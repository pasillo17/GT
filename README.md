# GIANITECH IMPORTADOS — Catálogo Oficial & E-Commerce Premium

Plataforma oficial de catálogo interactivo y pedidos mayoristas/minoristas de **Gianitech Importados**, especializada en tecnología Apple, consolas de videojuegos, bazar térmico de alta gama y perfumería importada.

---

## 🌟 Características

- **Catálogo Dual Dinámico**:
  - Modo **Minorista**: Precios por unidad con garantía y entrega inmediata.
  - Modo **Mayorista (5u+)**: Descuentos por volumen para revendedores y distribuidores.
- **Cotización Multidivisa**: Conversor instantáneo entre Pesos Argentinos (ARS) y Dólares (USD).
- **Checkout directo a WhatsApp**: Carrito interactivo que formula y envía el desglose del pedido de forma automática y detallada al WhatsApp oficial de Gianitech.
- **Buscador y Filtros Inteligentes**: Búsqueda en tiempo real por marcas (Apple, Sony, JBL, Lattafa, Afnan, Stanley) y categorías.
- **Diseño Ultra-Premium**: Interfaz moderna en modo oscuro (*obsidian*), adaptada para móviles y escritorio con micro-interacciones fluidas.

---

## 🚀 Tecnologías

- **React 19** + **TypeScript**
- **Vite** para desarrollo y compilación de ultra alto rendimiento
- **Tailwind CSS v4** para diseño responsivo
- **Lucide Icons**

---

## 🛠️ Instalación y Uso Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build
```
